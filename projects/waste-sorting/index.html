The project

The original project helps children learn waste classification through recognition, search and play. Little Sorters brings that learning flow to a standalone browser app.

Technical details

Learning and recognition

The game turns classification into repeated decisions with scoring and explanatory feedback. In the original recognition flow, Baidu returns candidate object names; the learner confirms a name before the dictionary supplies a category. The reports also document mistakes caused by background objects and ambiguous labels.

From WeChat to a browser app

The reconstruction preserves the original dictionary and adds an eight-object challenge, English/Chinese switching, category filters and locally stored best scores. The photo lab demonstrates the recognition-to-lookup process through recorded examples, while an optional local adapter supports live Baidu recognition with the user’s own keys.

Selected evidence

Outcome & scope

The rebuilt app supports English/Chinese, dictionary search and offline use. Its public photo lab is a recorded-example demonstration; live Baidu recognition requires the optional local server. Raspberry Pi was the original project context, with no completed Pi hardware prototype verified in the archive.
