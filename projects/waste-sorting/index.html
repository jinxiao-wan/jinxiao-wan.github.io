The project

The original project helps children learn waste classification through recognition, search and play. Little Sorters brings that learning flow to a standalone browser app.

My contribution

  • Developed the sorting game, scoring and feedback.
  • Integrated the game with a teammate’s recognition feature.
  • Documented the workflow and recognition-test limitations.

How it works

  1. 01

    Ask

    Photo input or an object-name query.

  2. 02

    Identify

    Review candidate labels or enter a name.

  3. 03

    Look up

    Map the object to the original dictionary.

  4. 04

    Practise

    Sort objects and read feedback.

Selected evidence

Outcome & scope

The rebuilt app supports English/Chinese, dictionary search and offline use. Its public photo lab is a recorded-example demonstration; live Baidu recognition requires the optional local server. Raspberry Pi was the original project context, with no completed Pi hardware prototype verified in the archive.

Full designs, source files and development details are in the project repository.
