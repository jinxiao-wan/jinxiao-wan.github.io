CASE STUDY 04 · APPLIED AI / PRODUCT

AI-assisted waste sorting learning system

A child-friendly learning product that connects image recognition, multimodal search and interactive practice across a WeChat Mini Program and Raspberry Pi context.

RoleProject lead
PeriodSep — Dec 2021
ProductMini Program + Raspberry Pi
AudienceChildren learning waste sorting

01 / PROBLEM

The challenge

Waste-sorting knowledge is easy to present as a static list but harder to turn into a habit. The project asked how recognition, search and play could reduce the effort of finding an answer while helping children repeatedly practise classification decisions.

02 / OWNERSHIP

My contribution

  1. 01Led the project from product framing through implementation and final reporting.
  2. 02Defined the learning flow around recognition, search, reference content and game-based practice.
  3. 03Developed the WeChat Mini Program interface and connected AI recognition services.
  4. 04Integrated photo input with classification candidates and user confirmation.
  5. 05Organized classification reference data and voice / text search paths.
  6. 06Coordinated the Raspberry Pi application context, testing and team delivery.

03 / SYSTEM
