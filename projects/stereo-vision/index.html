CASE STUDY 01 · COMPUTER VISION / ROBOTICS

Stereo vision for robotic teleoperation

A dual-camera perception pipeline that turns hand motion into stable 3D commands for UR5e teleoperation.

RolePerception & system integration
ContextLund University course project
StackPython · OpenCV · MediaPipe
Focus3D geometry · filtering · HRI

01 / PROBLEM

The challenge

A monocular prototype estimated depth from the apparent scale of the hand. It was simple, but the inferred z-coordinate changed with pose and camera perspective, producing unstable robot motion. The project moved to a calibrated stereo setup so depth could be recovered from geometry rather than scale heuristics.

02 / OWNERSHIP

My contribution

  1. 01Opened and synchronized two camera streams.
  2. 02Captured paired chessboard images and completed stereo calibration.
  3. 03Detected corresponding hand landmarks in both views with MediaPipe.
  4. 04Triangulated 3D hand coordinates from the calibrated camera matrices.
  5. 05Applied coordinate filtering and evaluated raw versus filtered trajectories.
  6. 06Connected stable position data to the robot-control pipeline and documented the system.

03 / ARCHITECTURE

System pipeline

01

Acquire

Synchronize two cameras and capture paired frames.

02

Calibrate

Estimate intrinsic, distortion and stereo extrinsic parameters.

03

Detect

Find corresponding MediaPipe hand landmarks in both images.

04

Triangulate

Recover 3D coordinates using the calibrated projection matrices.

05

Filter

Reduce coordinate noise before commands reach the robot controller.

06

Control

Map the stable hand position into continuous UR5e motion.

04 / EVIDENCE

Evidence from the implementation

05 / RESULT

Outcome

The stereo system improved depth estimation, teleoperation stability and overall robustness compared with the earlier monocular approach. The current evidence supports a qualitative improvement; a future evaluation should add repeated-trial error statistics, latency and task-completion metrics.
