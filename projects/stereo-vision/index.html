The project

Two cameras estimate hand position in 3D. Calibration, triangulation and Kalman filtering connect visual input to the robot-control pipeline.

My contribution

  • Stereo camera calibration and paired image capture.
  • Hand-landmark triangulation and coordinate filtering.
  • Robot control: hand-position mapping, motion commands and UR5e integration.
  • Integration and documentation with the project team.

Technical details

Perception and filtering

Paired camera views provide corresponding MediaPipe hand landmarks. Stereo calibration supplies the projection geometry for triangulation, and Kalman filtering reduces coordinate noise before the position is used for control.

Robot control

My work also included the robot-control pipeline: mapping the tracked hand position to robot motion commands and integrating that input with UR5e control. The project combines a keyboard positioning baseline with continuous hand-driven operation and supports an OnRobot gripper.

Selected evidence

Outcome & scope

The repository includes the camera workflow, filtering and robot integration. The available plots support a qualitative comparison; repeated-trial accuracy and latency benchmarks are not established.
