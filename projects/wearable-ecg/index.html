Technical details

Hardware and acquisition

The archived schematic connects a BMD101 ECG acquisition chip, TPS79333 regulator and BLE module labelled CC2640R2F. Original PCB routing, manufactured boards and SolidWorks render/prototype comparisons show the team’s path from circuit and enclosure design to physical parts.

Software and signal processing

The WeChat interface handles Bluetooth discovery, sample reception and waveform display. The reconstruction adds buffered packet parsing, checksum checks, recording and CSV export. Offline analysis includes filtering and R-peak detection; the public explorer lets visitors inspect a supplied MIT-BIH sample.

Selected evidence

Outcome & scope

The rebuilt repository includes original hardware evidence, repaired software and a public ECG explorer. Its beat-detection evaluation uses one supplied MIT-BIH record. Native CAD/fabrication files and clinical validation were not supplied.

Full designs, source files and development details are in the project repository.
